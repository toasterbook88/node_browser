NODE 0.9.10 adds share links for trails and puts the beta survey on the new tab page. Thank you for testing.

NODE updates itself on Windows, and on a Mac from 0.9.6 on. Copies of 0.9.5 or earlier on a Mac need this version downloaded by hand once.

## What's new

- **Share a trail as a link.** In File → Share Trail… (or **Share…** in Menu → Trail), **Create Link** makes a link you can paste anywhere. The trail is encrypted on your computer before it is uploaded, and the key is only in the link, so NODE's share server cannot read it. A link works for 30 days. **Your shared links** lists the links you made, with **Copy Link** and **Stop Sharing**.
- **Open a link.** Paste a share link into the address bar, or click one on a page, and NODE shows the same preview as a trail file: **Open as New Trail** or **Merge** into one of yours.
- **No NODE? No problem.** Someone without NODE can open the link in any browser and read the trail. The page has **Open in NODE** and **Download NODE**.
- **The beta survey is on the new tab page.** After you have used NODE on 3 different days, the new tab page shows a short survey section under the search box. Take the survey, choose **Later**, or **Don't ask again**. It is part of the page, not a pop-up.
- **NODE runs once.** Opening a trail file or a link from outside NODE now goes to the window you already have open.

If **Create Link** is not in the Share sheet yet, share links are still being switched on. **Save File…** works now, and links appear on their own once they are ready, with no update needed.

## Which file to download

Scroll down to **Assets** and download one file:

| Your computer | Download |
| --- | --- |
| Mac with an Apple chip (M1, M2, M3, M4 or later) | `NODE-0.9.10-mac-arm64.dmg` |
| Mac with an Intel processor | `NODE-0.9.10-mac-x64.dmg` |
| Windows | `NODE-0.9.10-win-x64.exe` |
| Linux | `NODE-0.9.10-linux-x86_64.AppImage` |

Not sure which Mac you have? Click the Apple menu in the top-left corner and choose **About This Mac**. If the line "Chip" says Apple M1, M2, M3 or M4, download the Apple chip file. If it says "Processor" with Intel, download the Intel file.

You can ignore the other files, including **Source code (zip)** and **Source code (tar.gz)**. They are for developers.

## Installing on a Mac

If you have 0.9.6 or later, NODE updates itself: when the update is ready it offers to restart. Otherwise:

1. Open the downloaded `.dmg` file.
2. Drag **NODE** into the **Applications** folder, replacing the old one if you have it.
3. Open NODE from Applications.

NODE is signed and checked by Apple, so it opens like any other app. Copies of 0.9.5 or earlier can't update themselves; download this version by hand once.

## Installing on Windows

1. If your browser warns about the download, choose **Keep**.
2. Open the `.exe` file. If you see "Windows protected your PC", click **More info**, then **Run anyway**.
3. Follow the installer.

Windows copies of NODE check for updates and install them by themselves.

## Installing on Linux

Download the `.AppImage` file, make it executable (right-click → Properties → Allow executing, or `chmod +x`), and open it.

## Known limits

- The first time NODE saves a password on a Mac, macOS may ask whether NODE can use its "Safe Storage" key in your keychain. Click **Always Allow**. If you are coming from 0.9.5 or earlier, it asks once more: click **Always Allow** again, or NODE can't read your saved passwords and API keys.
- Signing in to Google accounts opens in a separate Chrome-based window.
- Screenshots and saved pages are not included when you share a trail.
- On Windows, NODE is not listed under "Open with" for Markdown files. Use File → Open Shared Trail…, drag the file onto NODE, or choose **Open with → Choose another app** and pick NODE.
- On a Mac, passkeys (Touch ID / iCloud Keychain sign-in) are turned off; sites offer password sign-in instead.

## Reporting a problem

In NODE's menu bar, choose **Help → Report a Problem…**. NODE copies its diagnostics and opens a short bug form on GitHub. Paste them where the form asks, with what you were doing when it went wrong.
